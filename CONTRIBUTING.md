# Contributing

Thanks for your interest.

- **Issues are welcome**: bugs, unclear documentation, questions about the research method.
- **Bug fixes** can come as pull requests. Please add a test and run `pytest -q` before opening it.
- **New strategies or tuned parameters are not accepted** as pull requests. Every rule here passed a protocol
  written before its test; changing a rule after seeing its results would break that. If you have an idea, open
  an issue describing the rule and how it should be tested.
- Never include API keys, account IDs, ledgers or downloaded price history in a commit.

By contributing you agree that your contribution is licensed under the MIT license of this repository.
