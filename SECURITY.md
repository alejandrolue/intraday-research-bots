# Security

Please do not open a public issue for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** on this repository. Include what you
found, how to reproduce it and which files are affected. You will get an answer as soon as possible.

Never post API keys, account IDs or passwords in issues or pull requests. If you committed a key by mistake,
revoke it at your broker first; deleting the commit does not make it safe again.

This project only connects to Capital.com's demo API. It is not built or tested for real-money trading.
